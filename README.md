# 하루칸 업데이트 채널

이 공개 저장소는 하루칸 Windows 앱의 자동 업데이트 파일만 배포합니다.

- 소스 코드는 비공개 `Reboot-Together/harukan` 저장소에서 관리합니다.
- 설치 파일은 [Releases](https://github.com/Reboot-Together/harukan-releases/releases)에서 받을 수 있습니다.
- `update.json`은 하루칸 앱이 최신 버전과 SHA-256 무결성 정보를 확인할 때 사용합니다.
- 사용자 메모와 설정 데이터는 이 저장소에 업로드되지 않습니다.
